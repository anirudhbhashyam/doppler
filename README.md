# Doppler
Visualize the doppler effect using raylib.


# Running
Works only on `darwin`

```sh
bash ./build
./a.out
```

# Web build

You need to get the emscripten compiler. Follow the instructions [here](https://github.com/emscripten-core/emsdk.git).

```sh
bash build_web
```

Should generate a `web` directory. Serve the HTML there.
